# Images

Use **only** the approved image library: call `mcp_tbrain_cms_list_images` (optionally with `data_line` or `q`). Each entry has `image_url`, `title` and `image_description`, which says what the image actually shows and what kind of paragraph it suits. Choose by the description, never by the file name.

- Put each image next to the paragraph its description matches, followed by an `<em>` caption that tells the reader what to notice.
- The cover is a different library image from the inline ones; don't reuse a cover from a recent post (check `list_posts`).
- If nothing in the library fits a section, use fewer images and add a flag: "Section 3 needs an image of …". The team adds it to the library.
- Never use images from other sites, and never link to `/samples` (sample stills in the library may be shown, not linked).
