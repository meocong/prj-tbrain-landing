# Sources to scan

Use `web_search` and `web_extract`, and the browser only when a page needs JS. Prefer primary sources.

- arXiv listings, recent: cs.RO (https://arxiv.org/list/cs.RO/recent), cs.LG, cs.CV (egocentric video, VLA, world models)
- Hugging Face daily papers: https://huggingface.co/papers
- Hugging Face LeRobot blog/datasets: https://huggingface.co/lerobot , https://huggingface.co/blog
- Open X-Embodiment / RLDS ecosystem updates; Google DeepMind blog (Gemini Robotics, RT-x)

## Industry (primary blogs)

## News / analysis

## Practitioner pulse
- Reddit r/robotics, r/MachineLearning, r/reinforcementlearning; Hacker News front page threads on robotics/LLM data
- Use these to find questions people ask. Do not cite Reddit as evidence for a factual claim.

## Robotics data lines (check each week, rotate focus)
- **Game data / world models:** Google DeepMind (Genie, SIMA), NVIDIA Cosmos, Decart/Etched (Oasis), Microsoft Muse/WHAM, Matrix-Game / Skywork, Wayve GAIA, arXiv "world model" + "interactive video". Licensing and consent news about gameplay data.
- **Teleoperation:** ALOHA / Mobile ALOHA (Stanford, Google), LeRobot SO-100/101 and HF datasets hub, DROID, Open X-Embodiment, AgiBot World, UMI / UMI-on-legs, Galaxea / Fourier / Unitree data releases, Physical Intelligence data-collection posts.
- **Motion capture / humanoids:** AMASS, OmniH2O / HumanPlus / H2O, NVIDIA GR00T whole-body, Unitree / Figure / 1X / Agility humanoid learning posts, video-to-motion (WHAM, GVHMR), retargeting papers.
- **Hand pose / dexterity:** HaMeR, WiLoR, MANO, DexYCB, ARCTIC, HOT3D (Meta), dexterous hand vendors (Shadow, Inspire, Sharpa), glove capture.
- **Egocentric / exocentric:** Ego-Exo4D, Project Aria (Meta), EgoMimic, EgoScale (NVIDIA), HOI4D, EPIC-Kitchens updates.
- Conferences: CoRL (Nov), RSS, ICRA, CVPR / ECCV workshops on egocentric and embodied AI, NeurIPS datasets track.
